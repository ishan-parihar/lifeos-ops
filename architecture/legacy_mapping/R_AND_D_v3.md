### The cycle explained

1. **Trajectory** — past actions + experiences form the causational foundation for current actions. LifeOS aligns/redirects this causal chain toward the ideal future.

3. **Reflection** — processing the incoming catalysts (experiences generated by agency). This processing is ENHANCED by the prosthetic — the user can process more, deeper, faster than they could alone.

4. **Embodiment** — insights from reflection are digested as aligned behavioral patterns. These patterns become the FOUNDATIONAL CAUSATION for the next cycle's catalyst.

→ The embodied patterns become the new Trajectory. The cycle amplifies.

### Why this is a "causal amplification" cycle

- Each stage transforms its input into a more potent output
- The output of Embodiment (behavioral patterns) is MORE CAUSALLY POTENT than the input (raw insights) — because patterns compound
- The cycle doesn't just repeat — it AMPLIFIES (each loop, the user's causal capacity increases)
- LifeOS's intervention at each stage is what makes the amplification possible (without it, the cycle would be flat — just habit repetition)

## 3. LifeOS as the Intervention Layer

LifeOS is NOT a separate system. It's the **intervention layer at each interface** of the user's causal cycle. Each interface gets a specific mode of intervention:

### Interface 1: Trajectory — LifeOS provides the ALIGNMENT VECTOR

**What LifeOS does:** Doesn't just track the trajectory — it ALIGN/REDIRECTS it toward the ideal future.

**Structural components:**
- **Vision** = the ideal future (the teleological attractor that pulls the trajectory)
- **Values & Principles** = the alignment constraints (what the trajectory must not violate)
- **Annual-Goals / Quarterly-Goals** = the redirect mechanism (decomposes the ideal future into time-bound targets)

**Intervention mode:** Teleological pull. LifeOS doesn't push the user — it pulls the trajectory toward the attractor.

### Interface 2: Agency — LifeOS provides DECISION SUPPORT

**What LifeOS does:** Doesn't just capture decisions — it SHAPES them.

**Structural components:**
- **Projects / Tasks** = the aligned action hierarchy (translates goals into executable decisions)
- **Directives-and-Risks (− pole)** = corrective intervention (when agency drifts from trajectory, Directives redirect it)
- **Opportunities-and-Strengths (+ pole)** = leverage surfacing (when agency aligns with strengths, Opportunities amplify it)

**Intervention mode:** Bidirectional alignment. Agency generates data flowing IN; LifeOS sends alignment flowing OUT.

### Interface 3: Reflection — LifeOS provides COGNITIVE ENHANCEMENT

**What LifeOS does:** Doesn't just store reflections — it AMPLIFIES the user's capacity to process catalysts.

**Structural components:**
- **Synthesis Pipeline** (Notes → Opportunities/Directives) = the enhanced processing
- The user brings raw catalysts; LifeOS processes them into structured insights the user couldn't produce alone
- This is the "prosthetic" in consciousness-prosthetic — it extends cognitive capacity

**Intervention mode:** Amplification. The output (structured insights) is more potent than the input (raw catalysts).

### Interface 4: Embodiment — LifeOS provides DIGESTION SCAFFOLDING

**What LifeOS does:** Doesn't just track habits — it ENSURES insights digest as ALIGNED behavioral patterns.

**Structural components:**
- **Stats** = the behavioral pattern mirror (shows what's been embodied — the current trait profile)
- **6 Logs** = the real-time feedback signal (shows embodiment in action — are the patterns holding?)
- The digestion must be ALIGNED — patterns that don't serve the ideal future are not embodiment, they're calcification

**Intervention mode:** Scaffolding. LifeOS holds the structure that lets insights crystallize into patterns rather than dissipate.
